# NST Clubs

## Overview
NST describes student clubs as student-run communities that support technical, creative, cultural, and extracurricular activities.

The official NST student-life information currently lists examples including:
- Robotics Club
- Programming Club
- Software Development Club
- Google Developers Club
- Dance Club
- Sports Club

The actual club list on the NST Discord server may be broader or different.

## Discord club system
The NST Discord server can maintain:
- A role for each active club
- A private/public club channel
- A club coordinator role
- Club-specific announcements
- Club membership verification

## Joining a club
The AI assistant should tell students to check the current club-announcement or club-information channel for:
- Recruitment announcements
- Application forms
- Selection processes
- Coordinator contacts
- Recruitment deadlines

Do not invent a recruitment deadline or claim that a club is accepting applications unless that information exists in the current knowledge base or Discord data.

## Club coordinator verification
If the server uses coordinator-based membership verification, coordinators should verify members according to the server's current procedure.

The AI assistant should not grant club roles by itself unless a separately implemented, permission-controlled tool explicitly allows it.

## Club recommendations
If a student asks which club they should join, the bot can explain the focus of known clubs, for example:
- Programming: competitive programming and problem solving
- Software Development: building software and engineering projects
- Robotics: hardware, embedded systems, and robotics
- Google Developers: developer technologies and community activities
- Dance: dance and performance
- Sports: athletics and sports activities

These descriptions are general and should be updated when the server defines official club scopes.

Source: Official Newton School of Technology Student Life information, accessed August 2026.
