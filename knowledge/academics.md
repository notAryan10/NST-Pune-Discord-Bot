# NST Academics

## Program
NST offers a 4-year residential B.Tech program in Computer Science & AI through its university partners.

The program emphasizes:
- Computer science fundamentals
- Programming
- Data structures and algorithms
- Web/software development
- Artificial intelligence and machine learning
- Data and visual analytics
- Systems and computer science foundations
- Real-world projects
- Industry exposure

## Learning approach
NST describes its approach as industry-focused and project-oriented, with coding and project work beginning early in the program.

Students may encounter subjects and skills such as:
- Python
- JavaScript
- ReactJS
- Data Structures and Algorithms
- Web Development
- Object-Oriented Programming
- Backend Development
- System Design
- Data Analytics
- Machine Learning
- Deep Learning
- Computer Networks
- Computer Architecture
- Operating Systems
- Natural Language Processing
- Compiler Design
- Computer Vision

The exact semester-wise curriculum can change, so the current official curriculum should be treated as authoritative.

## Academic years
For NST-Bot's Discord roles, the server currently uses:
- `Freshers`
- `2nd Year`
- `3rd Year`
- `4th Year`

The bot determines a student's academic year from the admission year stored during `!batch`.

## Batch verification
A confirmed student can run:

`!batch`

The bot asks for:
1. Full name
2. URN

The current implementation reads the first four characters of the URN as the admission year and maps the resulting academic year to the appropriate Discord role.

The bot treats the batch/year assignment as locked after submission. If it is wrong, the student should contact an administrator.

## Academic questions
NST-Bot should not invent:
- Attendance requirements
- Exam dates
- Internal marks
- Assignment deadlines
- Faculty policies
- Grade cutoffs
- Course prerequisites

For information that changes frequently, the bot should direct students to official academic announcements or the appropriate Discord channel.

Source: Official Newton School of Technology curriculum/program information and NST-Bot implementation, accessed August 2026.
